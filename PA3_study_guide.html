Task 1Required

OPLoRA: Orthogonal Projection LoRA Prevents Catastrophic Forgetting during Parameter-Efficient Fine-Tuning

Yifeng Xiong, Xiaohui Xie · AAAI 2026 · arXiv:2510.13003 · read §3.2, §3.3 and Proposition 2

What it covers

The paper argues that LoRA forgets because its update can land on the directions that carry most of a pretrained weight's "energy", the leading singular vectors. §3.2 measures how much of an update falls there. §3.3 removes that overlap by projecting the LoRA factors, and Proposition 2 proves the protected singular triples survive exactly.

Key ideas and equations

Write the pretrained weight with its SVD and split off the top k directions:

W0 = UΣV⊤ = UkΣkVk⊤ + U⊥Σ⊥V⊥⊤

Interference metric (§3.2, Eq. 5). The fraction of the update's squared Frobenius norm inside the top-k output (column) space. This is exactly the ρk the assignment asks you to report.

ρk = ‖UkUk⊤ΔW‖F2 / ‖ΔW‖F2 ∈ [0, 1]

One-sided projection is not enough (Prop. 1). Using only PL = I − UkUk⊤ keeps every output of ΔW orthogonal to Uk, but it does not preserve the singular values or right singular vectors of W0.

Two-sided projection (Prop. 2). With PL = I − UkUk⊤ and PR = I − VkVk⊤, set ΔW = PLBAPR for any A, B. Then for i = 1…k:

(W0+ΔW)vi = σiui,   (W0+ΔW)⊤ui = σivi   ⇔   Uk⊤(W0+ΔW)Vk = Σk

Why it works: ΔW Vk = 0 because of PR, and Uk⊤ΔW = 0 because of PL. So the top-k block of W is untouched. Note what the proposition does not claim: the protected triples stay singular triples, but the update can still change everything else, and nothing guarantees that behaviour on any benchmark is preserved. The assignment makes this same point.

Factor form used in the assignment. Projecting the factors gives the same ΔW without building dense d×d projectors:

B̃ = B − Uk(Uk⊤B),   Ã = A − (AVk)Vk⊤,   ΔW = (α/r) B̃Ã = (α/r) PLBAPR

LoRA: Low-Rank Adaptation of Large Language Models

Hu et al. · ICLR 2022 · arXiv:2106.09685 · focus on §4.1 (parameterisation, initialisation, merging)

What it covers

Freeze the pretrained weights and learn a low-rank correction for selected matrices. The hypothesis is that the change needed for adaptation has low "intrinsic rank". After training, the correction can be merged into the weight, so inference costs nothing extra.

Key ideas and equations

h = W0x + (α/r) BAx,   A ∈ ℝr×din,   B ∈ ℝdout×r
  • Initialisation. A random, B = 0, so ΔW = 0 at step 0 and the model starts exactly at the pretrained checkpoint.
  • Scaling α/r. Keeps the update size roughly stable when you change r, so you do not need to retune the learning rate. The assignment uses α = 2r (8/4 and 32/16), so α/r = 2 for both ranks.
  • Merging. W = W0 + (α/r)BA is an ordinary dense matrix. Merged and unmerged outputs should match up to floating-point error.
  • Parameter count. r(din + dout) per adapted matrix, so going from r = 4 to 16 multiplies adapter parameters by exactly 4, as the PDF says.

Where it shows up in the code

common/lora.py:15LoRALinear: FP32 factors on a frozen FP16 base, kaiming-uniform A and zero B (lines 26–28), dropout on the input to the adapter path only.
common/lora.py:73inject_adapters wraps every q,k,v,o,gate,up,down_proj (Task 1) in deterministic order so the same seed gives the same A in LoRA-16 and OPLoRA-16.
common/lora.py:123merge_factors_into builds W0 + (α/r)BA in a fresh backbone; merge_export.py compares merged and unmerged logits.
task2_vlm/train.py:40Task 2 reuses the same class with r = 16, α = 32 on attention projections only, starting in Stage 2.

Explicit Inductive Bias for Transfer Learning with Convolutional Networks (L2-SP)

Li, Grandvalet, Davoine · ICML 2018 · arXiv:1802.01483

What it covers

When fine-tuning, the pretrained weights are a better prior than zero. The paper compares several regularisers and finds that penalising the squared distance to the starting point (the "SP") is a simple, strong default.

Key ideas and equations

Ω(θ, θ0) = ½ Σj=1P (θj − θ0,j)2,   ∇θ[λΩ] = λ(θ − θ0)
  • Ordinary weight decay pulls toward 0; L2-SP pulls toward θ0. A pretrained model is far from 0, so weight decay actively pushes away from what you want to keep.
  • L2-SP does not restrict which parameters move, only how far in total. Compare that with LoRA, which restricts the shape of the change.
  • Sum, do not average: with ~0.6B parameters, averaging would make λ = 10−3 negligible. The PDF insists on the sum and on counting tied embeddings once.

Where it shows up in the code

task1_finetune/train.py:193Ω = 0.5·Σ(p − θ0)² in FP32 over unique parameters, added as λΩ once per optimizer update (on the last microbatch). Ω, λΩ and total loss are logged (line 203).

common/lora.py:145unique_named_parameters makes sure the tied embedding is counted once.
configs/task1_ft.yaml:37l2sp_lambda: 1.0e-3.

What it covers

A careful comparison of LoRA and full fine-tuning on code and maths. LoRA usually reaches lower target-domain accuracy than full fine-tuning, but it also degrades the source-domain abilities less. Visual Instruction Tuning (LLaVA)

Liu, Li, Wu, Lee · NeurIPS 2023 · arXiv:2304.08485 · focus on the architecture and the two-stage training procedure

What it covers

LLaVA connects a frozen CLIP vision encoder to an LLM with a small projection, then trains in two stages. Stage 1 (feature alignment) trains only the projection on image–caption pairs, so visual features land in the LLM's embedding space. Stage 2 (instruction tuning) trains the projection and the LLM on GPT-generated visual conversations. The follow-up LLaVA-1.5 replaced the linear projection with a two-layer MLP, which is the connector you use.

Key ideas and equations

Hv = gφ(Zv),   Zv = vision_encoder(Xv)
p(Xa | Xv, Xinstruct) = Πt pθ(xt | Xv, Xinstruct, Xa,<t)

Loss only on answer tokens; image tokens and instructions are masked. Your assignment's version averages per example first, then across the batch, so a 2-token answer counts as much as a 60-token caption:

L = − (1/|B|) Σi∈B (1/|Ri|) Σt∈Ri log p(yi,t | Ii, qi, yi,<t)
LLaVAYour PA3 curriculum
Stage 1: projection only, image–caption pairsStage 1 caption alignment, connector only, 2,250 updates, LR 10−3
Stage 2: projection + full LLM, instruction dataStage 2 presence/counting + caption replay, connector + LoRA (r 16, attention only), 1,500 updates

Making the V in VQA Matter: Elevating the Role of Image Understanding in Visual Question Answering

Goyal, Khot, Summers-Stay, Batra, Parikh · CVPR 2017 · arXiv:1612.00837

What it covers

VQA v1 models could score well by learning language priors, such as answering "yes" to "Is there a…?" or "2" to "How many…?". VQA v2 balances the data: for each (image, question), annotators found a similar image where the same question has a different answer. These complementary pairs make the question text alone insufficient, and models trained on the old data lose accuracy on the balanced set.

Key ideas

  • Language prior: p(answer | question) learned without looking at the image.
  • Complementary pair: same question, two images, different answers. A blind model can get at most one of the two right if it gives the same answer to both.
  • Pair accuracy (both answers correct) is a far stricter grounding test than per-question accuracy.

How it maps to your evaluation

ΔNLL = NLL(y | q, Ipartner) − NLL(y | q, Icorrect) positive ⇒ the correct image makes the reference more likely

Sigmoid Loss for Language Image Pre-Training (SigLIP)

Zhai, Mustafa, Kolesnikov, Beyer · ICCV 2023 · arXiv:2303.15343

What it covers

CLIP-style image–text pretraining with a pairwise sigmoid loss instead of a batch softmax. Each image–text pair is treated as an independent binary classification, so the loss does not need a global normalisation over the batch.

L = − (1/|B|) Σi Σj log σ( zij · (t·xi·yj + b) ),   zij = +1 if i = j, else −1

Why it matters here

  • Your encoder google/siglip-base-patch16-224 splits a 224×224 image into 16×16 patches: 14 × 14 = 196 patch features of width 768.
  • You use the per-patch last_hidden_state (after the final LayerNorm, applied once), not the pooled embedding that the contrastive loss was trained on. The patches keep spatial layout, which counting and presence questions need.
  • The optional 49-token run averages 2×2 blocks of the 14×14 grid: 4× fewer visual tokens, at the risk of blurring small objects.

Scalable Best-of-N Selection for Large Language Models via Self-Certainty

Kang, Zhao, Song · NeurIPS 2025 · arXiv:2502.18581 · focus on the self-certainty definition and Borda voting

What it covers

A reward-model-free way to score a sampled response: measure how far each next-token distribution is from uniform, and average over the response. Peaked distributions mean the model was confident. The paper shows this scales better with N than perplexity or entropy, is less biased toward long responses, and combined with voting it beats plain self-consistency.

Key ideas and equations

Self-certainty(y) = − (1/(nV)) Σi=1n Σj=1V log( V · p(j | x, y<i) ) = (1/n) Σi KL(U ‖ pi)

In the assignment's notation, with ki,t read from the supplied kl_u_p column:

Ki = (1/Ti) Σt DKL(U ‖ pi,t),   Li = (1/Ti) Σt log pi,t(yi,t)
  • K vs L. Li only looks at the probability of the token that was sampled; Ki summarises the whole distribution at each step. KL(U‖p) heavily penalises putting near-zero mass anywhere, so it is not the same as entropy.
  • Borda voting. Rank responses by self-certainty, give rank r the vote (N − r + 1)p, sum votes per answer. p = 0 is majority voting; large p approaches "pick the top score".
  • The assignment's RWC is the linear case rescaled to [0, 1]: wi = (N − ri)/(N − 1), so the worst-ranked rollout gets zero vote.
  • Self-certainty alone loses to self-consistency on math with definite answers; the combination wins. Expect the same pattern in your MATH results.

Where it shows up in the code

task3_ttc/signals.py:39quartile_gap: top-quartile minus bottom-quartile correctness within a question, for the "what do the signals capture" analysis, plus the shortest-rollout control.

  • If longer rollouts tend to be wrong on MATH, which of Li, Ki and shortest-length would benefit? This is why the length control is required.
Task 3Required

VisConf: Quality-Aware Consensus for Best-of-N in Vision-Language Model Reasoning

Usman et al. · read §3–5 (calibration, fusion, RWC) · I could not find a public copy, so this section is built from the assignment's own description; check it against the PDF your instructor provided.

What it covers

For a VLM, confidence alone can reward fluent reasoning that ignores the image. VisConf multiplies a calibrated confidence by a visual engagement score (how much attention goes to image tokens), then uses rank-weighted consensus so that answer agreement still matters.

Key ideas and equations

Visual engagement, normalised over the three attention groups because the raw totals need not sum to one:

vi,t = Ai,timage / (Ai,timage + Ai,tprompt + Ai,tgenerated),   Vi = (1/Ti) Σt vi,t

Candidate-calibrated confidence. Pool every token KL in the current candidate set G and squash with its 5th/95th percentiles, so confidence is relative to the other candidates for this question:

ci,t = clip[0,1]( (ki,t − Q.05(G)) / max(Q.95(G) − Q.05(G), 10−8) ),   Ci = (1/Ti) Σt ci,t

Rollout-level fusion and its tokenwise ablation, which differ by exactly the within-rollout covariance:

Zi = ViCi,   Zitoken = (1/Ti) Σt ci,tvi,t,   Zitoken − Zi = Covt(ci,t, vi,t)

RWC with average ranks ri (1 = best):

wi = (N − ri)/(N − 1),   W(a) = Σi: ai=a wi,   â = argmaxa W(a)
  • Calibration must be recomputed on every prefix. Using all 32 rollouts to calibrate a selection at N = 4 leaks unseen candidates.
  • If confidence and vision are uncorrelated within a rollout, tokenwise and rollout-level fusion should rank candidates almost identically. That is the hypothesis your ablation tests.

Self-Consistency Improves Chain of Thought Reasoning in Language Models

Wang et al. · ICLR 2023 · arXiv:2203.11171

What it covers

Instead of one greedy chain of thought, sample many reasoning paths and return the most common final answer. Different correct paths tend to converge on the same answer, while errors scatter.

â = argmaxa Σi=1N 1[ai = a]
  • Works only when answers can be grouped, so answer equivalence (math-verify for MATH, MathVista's normalisation rules) directly changes the vote.
  • Missing extractions all fall into one NO_ANSWER group that can win the vote and is always graded wrong. Keep it; removing it would inflate scores.

Task 3Optional

Let's Sample Step by Step: Adaptive-Consistency for Efficient Reasoning and Coding with LLMs

Aggarwal, Madaan, Yang, Mausam · EMNLP 2023 · arXiv:2305.11860

What it covers

Most questions do not need all N samples: once the vote is lopsided, more samples rarely change the winner. Adaptive-Consistency samples one at a time and stops when a statistical criterion (for example, a Dirichlet/Beta posterior that the current majority stays the majority) passes a threshold. It cuts samples substantially with little accuracy loss.

How your version differs

  • You check only at n ∈ {4, 8, 16}, then stop at 32, and use simple thresholds: majority fraction ≥ τ (agreement controller), plus SC = RWC winner and RWC margin ≥ γ (quality-aware controller).
  • τ and γ are chosen on the dev split by the cheapest setting within 1 pp of fixed-32 SC, then frozen for held-out. That is a cost-constrained model-selection rule, and choosing on held-out data would be leakage.
margin = (W(1) − W(2)) / Σa W(a) W(2) = 0 if only one answer group

Compares an outcome reward model (scores the finished solution) with a process reward model (scores each step), trained on the PRM800K step labels.
